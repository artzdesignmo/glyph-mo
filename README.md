# Glyph Mo — Font Studio

Design your own display font in the browser. A complete A–Z + 0–9 glyph set you can morph, tweak and export as a real font file.

**Live demo:** https://artzdesignmo.github.io/glyph-mo/

## Features

- **36 glyphs** — full A–Z + 0–9 set, each independently editable
- **9 morph presets** — Normal, Rounded 圓滑, Sharp 尖銳, Dino 暴龍, Explode 爆炸, Flat 扁身, Tall 長身, Circle 圓形, Square 方形, Trapezoid 梯形
- **Fine controls** — weight, width, slant, rotate per glyph, or apply one design to all 36
- **Image → glyph** — upload any image, it gets vectorized into a glyph shape
- **Exports** — PNG/JPG charset sheet, **TTF font file** (generated in-browser via opentype.js), JSON save/load of your design
- EN / 繁中, white / silver / black themes

## Run

Open `index.html` in a browser. TTF export loads opentype.js from CDN on demand.
